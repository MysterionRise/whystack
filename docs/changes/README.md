# Cross-Cutting Change Requests

This directory records changes that alter the accepted product, experience, security,
data, or architecture baseline. Slice-local discoveries stay in their active Spec Kit
feature package.

Use filenames such as `CR-001-short-title.md` with:

- Status: proposed, accepted, rejected, or superseded.
- Requester, date, and affected inception baseline.
- Trigger and evidence.
- Product, experience, architecture, security, evaluation, and migration impact.
- Alternatives considered.
- Decision and approvers.
- Replacement artifact versions and hashes.
- Spec Kit features that must be created, amended, or stopped.

An accepted request produces a new BMAD baseline and implementation-readiness review
before affected work resumes. Change requests never edit an already accepted baseline in
place.
